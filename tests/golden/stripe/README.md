## Security notes

- Authentication uses `Authorization` (model: `bearer`).
- Request bodies are sent as `form`.
- Attribution is not required by this provider.
- Provider SDKs are **never** copied into this project. Where an SDK would help,
  declare it as an ordinary dependency instead of vendoring it.

## Reconciliation

Webhooks can be missed: providers retry, but networks and deploy windows are
real. Reconcile against the provider, not against local state.

- `GET /v1/payment_intents/{id}` is the authoritative record for a payment. When an
  event is missing or ambiguous, re-fetch by identifier rather than trusting the
  local ledger.
